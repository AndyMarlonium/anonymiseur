Anonymiser

Importez un document : les informations personnelles (noms, dates, adresses…) sont repérées automatiquement.

Étape 1

PDF (scanné ou natif), Word (.docx) ou texte (.txt).

Étape 2

Copie le texte anonymisé dans le presse-papiers (prêt à coller dans une IA externe) et vide le champ.

Étape 3

Collez ici (Ctrl+V) le texte renvoyé par l'IA, puis cliquez ici pour remettre les vraies données à la place des pseudonymes.

Enregistrer le document final (désanonymisé) sur votre ordinateur.

Recommencer avec un autre document à anonymiser.

Vous pouvez aussi coller ou taper le texte original directement ci-dessous (Ctrl+V), puis cliquer sur « ↻ Redétecter les entités ».
